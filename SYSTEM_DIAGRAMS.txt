NOTES
═══════════════════════════════════════════════════════════════════════════════

1. All communication between components is asynchronous where possible
2. Video and audio use separate threads for capture to avoid blocking
3. MQTT runs in its own thread managed by Paho MQTT library
4. WebSocket server runs in the main asyncio event loop
5. Ngrok tunnels are created at startup and maintained throughout runtime
6. All components support graceful shutdown via signal handling
7. Error handling and reconnection logic is built into each component
8. Statistics and logging are integrated throughout the system
