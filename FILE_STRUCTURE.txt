🚀 EXECUTION FLOW
=================

1. User runs: ./setup.sh
   → Installs all dependencies
   → Configures Mosquitto
   → Creates systemd service

2. User runs: ./run.sh
   → Activates virtual environment
   → Starts main.py

3. main.py executes:
   → Initializes MQTT controller
   → Connects to Mosquitto broker
   → Subscribes to topics
   → Initializes WebSocket server
   → Starts Ngrok tunnels
   → Starts video/audio streaming
   → Enters event loop

4. System running:
   → Video frames captured and broadcast
   → Audio chunks captured and broadcast
   → MQTT messages routed to WebSocket
   → WebSocket commands published to MQTT
   → Statistics logged periodically

5. User connects:
   → Opens client_example.html
   → Connects to WebSocket URL
   → Receives video/audio streams
   → Sends motor commands
   → Views statistics
